## Optional Jev-on advisory clarification ranking

Use this append guidance only when **Jev-on mode** is active, the instrumented tools are available, and more than five explicit ambiguity candidates exist. Form an explicit set of **2 to 50** ambiguity candidates with stable opaque IDs, retaining the complete ambiguity set and the original decision context outside telemetry.

Only `jev_rank` is the measured Jev interface; never use raw shell or MCP Jev. Do not send credentials, secrets, personal data, or unauthorized sensitive payloads. Ask `jev_rank` only to rank the value of asking each candidate within the five-question limit. It cannot make a product, architecture, privacy, permission, cost, security, or irreversible decision automatically.

The main agent selects at most five questions and handles every material product, architecture, privacy, permission, cost, security, or irreversible decision. Record `jev_disposition` for each reviewed proposal as accepted, overridden, or not used; proposals without a disposition remain pending. If Jev-on is absent or `jev_rank` returns no proposals, use the unchanged manual workflow.

No more than five questions are asked and each accepted answer is integrated and validated by the core command.
