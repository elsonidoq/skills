## Optional Jev-on advisory checklist ranking

Use this append guidance only when **Jev-on mode** is active, the instrumented tools are available, and **after the complete candidate set exists**. Form an explicit set of **2 to 50** checklist inclusion candidates and near-duplicate group candidates with stable opaque IDs. Retain the complete checklist candidate set and every original requirement-quality input outside telemetry.

Only `jev_rank` is the measured Jev interface; never use raw shell or MCP Jev. Do not send credentials, secrets, personal data, or unauthorized sensitive payloads. Ask `jev_rank` only to rank inclusion value and likely near-duplicate grouping. It cannot exclude coverage, modify files, or decide requirement quality.

The main agent reviews every exclusion and group, retaining required, high-risk, and owner-requested coverage. Record `jev_disposition` for each reviewed proposal as accepted, overridden, or not used; proposals without a disposition remain pending. If Jev-on is absent or `jev_rank` returns no proposals, use the unchanged manual workflow.

Preserve requirement-quality focus and existing file-preservation rules.
